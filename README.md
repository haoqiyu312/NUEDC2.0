按年份和题目保存训练资料。每道题的说明、方案、采购、仿真和实物记录放在同一个题目目录。

## 目录约定

```text
training/<年份>/<题目简称>/
├── README.md       # 题目说明、进度和文件导航
├── problem/        # 原题、题图
├── design/         # 方案和原理
├── bom/            # 器件清单
├── simulation/     # 仿真工程、脚本和结果
└── hardware/       # 实物、接线和测试记录
```

按实际资料建立子目录；暂时没有资料时无需创建空目录。新题可参考 [题目说明模板](templates/problem-README.md)。

日常修改从 `main` 创建临时分支，核对后合并回 `main`。题目长期保存在 `training/`，分支只记录修改过程。
