# NUEDC 2.0 — 帆板控制系统

2027 年电子设计竞赛校级训练队招新选拔测试题（**控制方向**）的参赛作品资料。

**作品形态：** 纯模拟电路实现的帆板角度闭环控制系统——人拧面板电位器设定角度，电路测出帆板实际角度、算出偏差，用 PWM 调节风扇转速，用风力把帆板吹到设定角度。

**关键约束（题目硬性要求）：**
- 纯模拟电路，**不得使用任何单片机或可编程器件**
- 全部电路焊在**洞洞板**上
- 整体为**一个机械结构**，不得分离
- 需通过 **0.2m 自由落体**测试，摔后不许调试、不许修复
- 转轴处**必须装量角器**
- 风扇**不得带自动调速**功能

## 系统一句话

```
角度设定电位器 → 跟随器 ┐
                        ├→ 减法器 → 误差 → PI 控制器 → PWM → MOSFET → 风扇
角度反馈电位器 → 跟随器 ┘        ↑                                    │
                              2.5V 中点基准             风力吹帆板 ←──┘
                                                            （帆板转 → 带动反馈电位器）
```

**只用 4 个芯片**：3 片 LM358（双运放，共 6 个运放）+ 1 片 LM393（双比较器）+ 1 片 7805（稳压）。

---

## 关键参数（定稿值）

| 项目 | 值 |
|------|-----|
| 运放 / 比较器供电 | **12V** |
| 信号域 | **0~5V**，中点 **2.5V** |
| 误差 | `V_err = 2.5V + (V_fb − V_set)` |
| PI 参数 | R7=**100k**、R8=**22k**、C1=**6.8µF 薄膜** → Kp=0.22，Ti=0.68s |
| 三角波 | **0.95~4.23V**、**2.31kHz**（以实测 V_L/V_H 为准） |
| 占空比 | `(V_ctrl − V_L)/(V_H − V_L)` |
| 帆板 | 10×15cm，**质量 ≤10 克** |
| 配重 | 对轴质量矩 **20~30 g·cm** |
| 距离 d | 基本要求 **15cm**；发挥部分 **10~25cm** |

## 复跑仿真

```bash
python sim/fanvane_sim.py
```

只依赖 numpy，跑完约 25 秒，会重新生成 `sim/sim_output.txt`。

仿真验证了：电路拓扑与极性、PI 参数取值范围、闭环稳定性、帆板阻尼与配重需求、距离 d 的可行性。
**仍待实物实测**：三角波实际限值、风扇响应曲线、帆板真实阻尼、角度—电压映射。
