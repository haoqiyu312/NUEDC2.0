# 帆板控制系统（控制方向）

2027 年电子设计竞赛校级训练队招新选拔测试题 —— 参赛作品资料。

**作品形态：** 纯模拟电路实现的帆板角度闭环控制系统。人拧面板电位器设定角度，电路测出帆板实际角度、算出偏差，用 PWM 调节风扇转速，用风力把帆板吹到设定角度。

**题目硬性约束：**
- 纯模拟，**不得使用任何单片机或可编程器件**
- 全部电路焊在**洞洞板**上
- 整体为**一个机械结构**
- 需通过 **0.2m 自由落体**，摔后不许调试、不许修复
- 转轴处**必须装量角器**
- 风扇**不得带自动调速**功能

## 系统一句话

```
角度设定电位器 → 跟随器 ┐
                        ├→ 减法器 → 误差 → PI → PWM → MOSFET → 风扇
角度反馈电位器 → 跟随器 ┘        ↑                          │
                             2.5V 中点基准        风力吹帆板 ←┘
                                              （帆板转 → 带动反馈电位器）
```

4 个芯片：3 片 LM358（6 个运放）+ 1 片 LM393（2 个比较器）+ 1 片 7805。

## 关键参数

| 项目 | 值 |
|------|-----|
| 运放 / 比较器供电 | **12V** |
| 信号域 | **0~5V**，中点 **2.5V** |
| 误差 | `V_err = 2.5V + (V_fb − V_set)` |
| PI | R7=**100k**、R8=**22k**、C1=**6.8µF 薄膜/25V**（或 2.2µF） |
| PI 参数 | Kp = R8/R7 = **0.22**；积分时间常数 R7·C1 = **0.68s**；积分系数 1.47 s⁻¹ |
| 三角波 | **0.95~4.23V**、**2.31kHz**（计算值，以实测 V_L/V_H 为准） |
| 占空比 | `(V_ctrl − V_L)/(V_H − V_L)` |
| 栅极驱动 | A7 上拉 **2.2k**（定三角波）；A8 上拉 **1k**（栅压约 4.55V） |
| 帆板 | 10×15cm，**质量 ≤10 克** |
| 配重 | 对轴质量矩 **20~30 g·cm**（≤34 才够 d=25） |
| 距离 d | 基本要求 **15cm**；发挥部分 **10~25cm** |

> **关于 `0.68s` 的命名**：它是**积分时间常数** R7·C1，不是标准 PI 形式 `Kp(1+1/(Ti·s))` 里的 `Ti`。
> 两者差一个 Kp：`Ti_标准 = Kp × 0.68s = 0.15s`。仿真脚本里 `ti` 参数也是指前者。

## 验证边界（重要）

**已验证：**
- 减法器公式与极性 —— Multisim，6 组数据
- PI 起点 / 斜率 / 饱和 —— Multisim 波形
- PWM 极性与单调性 —— Multisim，5 组数据
- 闭环稳定性、参数范围、配重与距离可行性 —— 数值仿真

**未验证（不可当作承诺）：**
- 三角波实际幅度与频率（Multisim 的 LM393 是推挽模型，振荡不起来）
- 栅极高电平与 MOS 温升（4.55V 是算的，需接真实风扇实测）
- 风扇真实风量曲线
- 帆板真实阻尼 ζ
- 转轴静摩擦
- C1 实物尺寸（6.8µF 薄膜可能是 20~26mm 长的大件）

详见 [design/整体方案指南.md](design/整体方案指南.md) 第 17 节。
