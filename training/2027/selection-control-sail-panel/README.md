# 2027 校级训练队招新选拔题 — 帆板控制系统

控制方向的纯模拟帆板角度闭环控制方案。设定电位器给出目标角度，反馈电位器测量实际角度，电路根据偏差调节风扇。

## 已记录的约束

- 使用模拟电路，不使用单片机或可编程器件。
- 电路焊在洞洞板上，整机为一个机械结构。
- 转轴安装量角器；风扇不带自动调速。
- 需要通过 0.2 m 自由落体测试，摔后不可调试或修复。

## 控制链路

```text
角度设定电位器 ─┐
                ├─→ 减法器 → PI 控制器 → PWM → MOSFET → 风扇 → 帆板
角度反馈电位器 ─┘                                  ↑         │
                  ←──────── 反馈电位器随帆板转动 ───────┘
```

目前方案记录使用 3 片 LM358、1 片 LM393 和 1 片 7805。关键参数和计算见[整体方案指南](design/整体方案指南.md)，实物参数需要测量与标定。
