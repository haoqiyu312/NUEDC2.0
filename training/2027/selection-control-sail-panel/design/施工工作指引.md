# 施工工作指引（压缩版 · 面包板优先）

> **配套：**《整体方案指南》= 原理与参数（查细节）
> **本文 = 照着做的顺序**（动手用）
> **前提：** 元件已到货、零基础、**时间紧**
> **工期：** **4 天 × 5~6 小时 ≈ 22 小时**（原 8 天 40 小时的压缩版）

---

## 0. 为什么可以压缩 / 压缩掉了什么

| 原计划 | 现在 | 省下的时间 |
|--------|------|-----------|
| 焊练习板 3 小时 | **1 小时**（只练 10 个电阻） | 2h |
| 焊完洞洞板再调 | **面包板先验通，再照抄焊** | 返工少 3~5h |
| 机械单独 1 天 | **和洞洞板焊接并行** | 5h |
| 8 项测试分两次 | **一次过完** | 1h |
| 8 天排期 | **4 天** | 4 天 |

**省下的核心逻辑：面包板不焊，改一根线 5 秒；洞洞板改一根线 20 分钟。**
先把所有极性、参数、波形在面包板上确认完，再"照抄"到洞洞板，**几乎不会出错**。

> ⚠️ **压缩的前提是并行。** 3 个人分工；如果只有你一个人，把 4 天改回 6 天，别硬扛。

## 2. D0 晚：验货 + 面包板准备（1.5 小时）

### 2.1 验货（30 分钟，不能省）

| 关键件 | 怎么验 | 不合格 |
|--------|--------|--------|
| C1：6.8µF 薄膜 | 量长×宽×脚距 | 记下尺寸，布局要用 |
| 624ZZ 轴承 | 看封盖是**金属**还是橡胶 | 橡胶=错货 |
| **P1：B10K** | 转中间量阻值 ≈5kΩ | 偏离=A/C 型 |
| **P2：WDD35D4** | 量两端阻值 = 标称值；转动时滑动端 0→标称值平滑变化 | 不平滑=坏 |
| **轻触开关** | 不按时量两端，应**断开** | 一直通=接错脚（4 脚开关要对角接） |
| 风扇 | 数引线 | 必须 2 根 |
| 帆板材料 | 称重 | ≤10 克 |
| LM358/LM393 | 看是两排长脚（DIP-8） | 贴片=焊不上 |

### 2.2 面包板布局（30 分钟）

用**两块面包板**（或一块大板），按"从左到右"分三段：

```
┌──────────────┬──────────────┬──────────────┐
│  电源区       │   信号区      │   功率区      │
│              │              │              │
│ 12V 入口      │ A1 2.5V基准  │ A8 PWM       │
│ 7805 → 5V    │ A2 P1跟随    │ R12/R13      │
│ 2.5V 分压     │ A3 P2跟随    │ IRLZ44N      │`n│              │  (WDD35D4)   │              │
│ 470µF/10µF   │ A4 减法器    │ 1N4007       │
│              │ A5 PI        │ 风扇端子      │
│              │ A6/A7 三角波  │              │
└──────────────┴──────────────┴──────────────┘
```

**面包板两条长边是电源轨**：上轨接 12V（或 5V），下轨接 GND。**先把两条轨接好再插元件。**

### 2.3 面包板三个注意

| 注意 | 说明 |
|------|------|
| **电源轨不是一条** | 多数面包板的电源轨中间断开，**要自己用跳线连左右** |
| **元件脚要插到底** | 半插=虚接，最难查 |
| **C1 用薄膜** | 6.8µF 脚较粗，弯一下能插；插不稳可临时用 **2.2µF**（你也买了），焊洞洞板时换回 6.8µF |

## 3. D1：面包板搭全链（6 小时）★ 最关键的一天

> 电路细节见《整体方案指南》§5.0~§5.8
> **今天的目标：在面包板上看到 PWM 占空比随 V_ctrl 变化。** 做到这一点，整套电路就通了。

### 3.1 搭的顺序（一步一步测，别一次插完）

| 步 | 搭什么 | 立刻测 | 合格标准 |
|----|--------|--------|---------|
| 1 | 12V 入口 + 7805 | 量 12V、5V | 12.0±0.5 / 5.00±0.1 |
| 2 | 2.5V 基准（10k+10k+A1） | 量 A1 输出 | **2.50±0.05** |
| 3 | P1 跟随器（A2） | 转电位器 | 0~5V 均匀 |
| 4 | P2 跟随器（A3） | 转 **WDD35D4** | 单调变化；**每度约 14.5mV，50° 约 725mV** |
| 5 | 减法器（4×10k＋A4） | **极性自检** | 见 3.2 |
| 6 | PI（R7/R8/C1＋A5） | V_err 偏离 2.5V | 先小跳、再匀速移动 |
| 7 | 三角波（A6/A7） | 示波器看 A6 输出 | **记录 V_L、V_H、频率** |
| 8 | PWM（A8） | V_ctrl 升，看占空比 | **0→100% 单调变宽** |

> **每步测完再进下一步。** 面包板上错一根线，八步一起搭完你根本找不到是哪根。

### 3.2 ★ 减法器极性自检（10 秒，今天最关键的检查）

固定 V_set = 2.50V，把 V_fb 从 2.50V 调到 3.00V：

```
输出必须从 2.50V 升到 3.00V
```

- ✅ 升上去 → 对
- ❌ 降到 2.00V → **V_fb/V_set 接反**，立刻对调

> 接反的后果**不是度数不准，是正反馈**——角度越偏，风扇越往偏的方向推，直接失控。
> **在面包板上发现，改一根线；在洞洞板上发现，拆半小时。**

**两个必错点：**
1. 减法器那个 10k 的下端接 **2.5V，不是 GND**
2. 走 **(+)** 的那路接 **V_fb**，走 **(−)** 的接 **V_set**

### 3.3 三角波：今天必须拿到真实数据

**这是之前 Multisim 没验成的部分**（LM393 模型是推挽，振荡不起来），面包板能直接给答案。

示波器接 A6 输出，记录：

| 项目 | 理论值 | **实测（填）** |
|------|--------|---------------|
| 下限 V_L | 0.95 V | ______ |
| 上限 V_H | 4.23 V | ______ |
| 频率 | 2.31 kHz | ______ |

> **这三个数后面 PWM 和调参全要用，写在纸上贴墙。**
> 频率落在 2.0~2.7 kHz 都正常（电阻电容有容差）。

**没有波形 → 先查 A7 的 2.2k 上拉。** 开漏输出，不加上拉一点波形都没有。

### 3.4 PWM 验证

| V_ctrl | 占空比应 |
|--------|---------|
| 略低于 V_L | 0%（全低） |
| 中间 | 约 50% |
| 略高于 V_H | 100%（全高） |

**越调越窄 = A8 正负接反，立刻改。**

> 注意：A7 上拉 **2.2k**，A8 上拉 **1k**，两个值不一样。面包板上可以先都用 2.2k 验证功能，
> **焊洞洞板时 A8 必须换 1k**（栅压才够 4.55V）。

### 3.5 今天收工前

- [ ] 面包板上 PWM 占空比能随 V_ctrl 连续变化
- [ ] 记录了 V_L / V_H / 频率
- [ ] **拍照**：面包板全景（正上方拍），焊洞洞板时照着抄
- [ ] 每个节点的电压写在纸上

## 4. D2：洞洞板焊接 ∥ 机械（6 小时，两人并行）

### 4.1 A 同学：焊洞洞板（照面包板抄）

> **别自己重新想接线，面包板已经验证过了，照抄最快。**
> 布局见《整体方案指南》§7.1

**焊接顺序（每焊一个模块就测一次，和面包板对比）：**

| 序 | 焊什么 | 焊完立刻测 |
|----|--------|-----------|
| 1 | 4 个 DIP-8 插座（缺口朝上） | 通断 |
| 2 | **地线整条 + 镀锡加粗** | 通断到每个 GND 点 |
| 3 | 电源：DC-005、保险丝、开关、LED+1k、470µF、7805 | LED 亮，5V 对 |
| 4 | TP1~TP8 排针 | 通断 |
| 5 | 2.5V 基准 + 两个跟随器 | 2.50V 对 |
| 6 | 减法器 4×10k | **极性自检** |
| 7 | PI（R7/R8/C1/复位键） | 先跳再匀速 |
| 8 | 三角波（R9/C2/R10/R11，**A7 上拉 2.2k**） | 记录 V_L/V_H，和面包板差多少 |
| 9 | PWM（**A8 上拉 1k**） | 占空比单调 |
| 10 | 功率级（IRLZ44N、100Ω、10k、1N4007、100µF） | 见 D3 |

> **第 10 步先别接风扇**，D3 测完栅极波形再说。

**焊接三条铁律：**
1. 芯片**最后插**，焊完插座、测完电源再插
2. 每焊完一个模块，**用通断档量一遍**再焊下一个
3. 电解电容**长脚正、灰带负**；1N4007 **白环=阴极**

### 4.2 B 同学：机械（同时进行）

**顺序不能颠倒：**

1. 下料：底板 + 两块侧板（5mm 板，24 高 × 12 宽）
2. **打轴承孔**：13mm 阶梯钻，一次钻透（别来回磨，会偏心）
3. 压入 624ZZ（略紧）；太松垫薄纸
4. 穿 4mm 光轴，加轴环（轴向窜动 <0.5mm）
5. 装 **WDD35D4**（侧板外侧，**孔对准轴承孔**；先把帆板放 35°，把电位器转到行程中间再套上）
6. 接硅胶管（4mm 光轴套 2~3 层热缩管垫到 6mm，再套硅胶管）
7. 装帆板（上沿夹紧 + 定位销，**不要只靠摩擦**）
8. 装配重杆 + 可滑动配重
9. 贴量角器（靠近帆板那侧外侧，圆心对准轴心）

**三个验收（不用仪器）：**

| 测试 | 方法 | 合格 |
|------|------|------|
| 灵活度 | 手指轻推帆板 | 毫无阻滞摆几秒 |
| **摩擦预算** | 离轴 5cm 挂回形针（0.5g） | **帆板自己转起来** |
| 轴向窜动 | 前后推拉轴 | <0.5mm |

> **回形针测试转不动 = 摩擦超预算**：撬掉轴承防尘盖 + 滴一滴缝纫机油（**别用黄油**），或换 PTFE 衬套。

### 4.3 C 同学：机械数据 + 记录

- 量并记录：帆板质量、对轴质量矩、轴高、侧板间距
- **测阻尼**：风扇断电，帆板拨到 45° 松手，数来回摆几次

| 摆几次 | ζ | 判断 |
|--------|---|------|
| 4 个以上 | <0.05 | 基本勉强，发挥没戏 → **要加阻尼** |
| 3 个 | ≈0.06 | 基本能过 |
| 2 个 | ≈0.08 | 都能拿 |
| 1 个就停 | ≥0.20 | 理想 |

**加阻尼三招**：轴上加小挡风板 / 滴硅油 / 磁铁+铜片涡流

## 5. D3：洞洞板测试 + 功率级 + 闭环（6 小时）

### 5.1 上电顺序（救芯片）

| 步 | 做什么 | 合格 |
|----|--------|------|
| **0** | **先量适配器极性**（不接板）：黑笔外壳、红笔中心针 | **+12V**；−12V 先对调线 |
| 1 | 开关 OFF，接 12V | LED 亮 |
| 2 | 量 4 个插座脚 8 对脚 4 | 全是 12V |
| 3 | **断电**，量 12V 对 GND 电阻 | **>100Ω** |
| 4 | 插芯片，开关 ON | 芯片不烫 |
| 5 | 量 TP2 | 2.50V |

### 5.2 八项测试（一次过完）

| # | 模块 | 合格标准 |
|---|------|---------|
| ① | 电源 | LED 亮；12.0±0.5 / 5.00±0.1 / 2.50±0.05 |
| ② | 设定通道 | 0~5V 均匀 |
| ③ | 反馈通道 | 连续单调，**记录 10°/45°/60° 三点** |
| ④ | 减法器 | V_err=2.5+(V_fb−V_set)，**V_fb 大→输出大** |
| ⑤ | PI | 先跳再匀速 |
| ⑥ | 三角波 | 连续斜坡；**和面包板实测值差 <10%** |
| ⑦ | PWM | 占空比 0→100% 单调 |
| ⑧ | 功率 | 风扇 停/中速/全速；MOS 不烫 |

### 5.3 ★ 接风扇前必做（不做可能烧管）

1. 示波器量 **G 对 S**：高电平 **≥4.4V**，上升沿 **<10µs**
2. 风扇跑 **10 分钟**，摸 MOS：**烫手（>60℃）= 驱动不足**
3. 记录占空比 100%/50% 的栅压和温度

**烫手怎么办**：A8 上拉从 1k 降到 **470Ω**（栅压 4.8V），或加一级 NPN 射极跟随器。

### 5.4 接风扇 + 粗调配重

1. 接风扇，转 V_ctrl（用 P1 直接给也可以），确认风扇能**停/中速/全速**
2. 把设定拧到最大，看帆板能不能吹到 **68~72°**
   - 到不了 → 配重**往上移**（远离轴）
   - 超过 72° 或撞限位 → 配重**往下移**（靠近轴）

## 6. D4：调参 + 标定 + 自由落体（5 小时）

### 6.1 闭环调参（2 小时）

**标准值起调：R7=100k / R8=22k / C1=6.8µF**

给 **20°→45° 的阶跃**（手拨到 20°，设定拧到 45°），掐表：

| 现象 | 改 C1 |
|------|--------|
| 来回摆 / 撞 78° 限位 | **加大**到 10µF |
| 太慢（>5s） | **减小**到 4.7µF |
| 45° 附近小幅抖 | 加到 10µF |

**判据：5 秒内进 40~50° 并停住。**
**R8 最多调到 47k，别超。**

### 6.2 角度标定（20 分钟）

1. 帆板靠下位限位（10°），记 V_fb
2. 找到 45°，记 V_fb
3. 举到 60°，记 V_fb
4. 在面板电位器刻 **7 个**记号（10/20/30/40/45/50/60）——P1 和 P2 斜率不同，标 3 个不够
5. 复核：转到 45° 刻度，5 秒内稳在 45°±5°

### 6.3 加固 + 自由落体（2 小时）

**必做：**
- [ ] 所有连接 M3 螺丝 + 尼龙螺母，**不许只用胶**
- [ ] 底座底面压 2mm 铁板
- [ ] **电位器不承重**（硅胶管柔性连接）
- [ ] 帆板螺丝夹紧 + 定位销
- [ ] 配重热熔胶 + 扎带双固定
- [ ] 量角器透明胶带包边
- [ ] 飞线全部扎带固定
- [ ] **电源线离焊点 3cm 处扎带固定**
- [ ] 大电流节点补焊饱满
- [ ] **不要垫海绵缓冲**

**自由落体 0.2m，摔完不许调参、不许修。摔完 30 秒自检：**
1. 通电，量 TP2/TP3/TP4 正常
2. 转 P1，角度能跟着动
3. 帆板手推能自由摆动
4. **直接按 45° 刻度测**

## 7. 面包板 → 洞洞板 转移防错（D2 专用）

**最大的返工来源就是"照抄抄错"。** 四个办法：

| 办法 | 做法 |
|------|------|
| **① 拍照** | 面包板正上方拍全景，焊的时候放旁边对照 |
| **② 节点贴标** | 用美纹纸写"2V5""V_err""V_ctrl"贴在关键节点上 |
| **③ 分模块搬** | 每搬一个模块就测，**不要一次搬完** |
| **④ 边测边比** | 洞洞板该点的电压和面包板**差 <5%** 才算对 |

> **不要凭记忆搬。** 面包板上 15 根线，凭记忆必错。

## 8. 面包板的三个局限（别被误导）

| 局限 | 影响 | 应对 |
|------|------|------|
| 接触电阻 10~50mΩ | 大电流下 12V 会掉 | 功率级别在面包板上长期跑，测一下就行 |
| 寄生电容/电感 | 高频不稳 | 本题只有 2.3kHz，**不受影响** |
| 虚接 | 时好时坏，最难查 | 每根线插到底，测之前晃一下板子 |

> **好消息：本题信号都很慢**（三角波 2.3kHz、闭环带宽约 1Hz），**面包板完全够用**。
> 唯一要小心的是功率级——大电流会发热、压降大，**验证转速即可，别长时间满负荷跑**。

## 9. 卡住时的求助顺序

| 症状 | 先查 | 指南章节 |
|------|------|---------|
| LED 不亮 | 电源极性 / 保险丝 / 开关 | §5.0b |
| 一上电断保险丝 | 12V 对 GND 短路 | 故障表 |
| 风扇不转 | 共地 / 1N4007 方向 / 栅极虚焊 | §13 |
| 角度反着动 | 减法器或 PWM 的 +/− | §5.4、§5.7 |
| 三角波没有 | **A7 的 2.2k 上拉** | §5.6 |
| **占空比最多 60% 左右** | **积分器失效**：轻触开关接成常闭（4 脚要对角接）/ C1 接成并联 | §5.9.14 |
| **占空比最多 78% 左右** | VC 最高只到 3.5V → **芯片3 pin8 接了 5V**（应 12V） | §5.9.14 |
| MOS 烫手 | 栅压不足（A8 上拉要 1k） | §5.8 |
| 到不了 60° | 配重太靠近轴（质量矩 >34 g·cm） | §4.3 |
| 10° 下不去 | 摩擦超预算 / 配重太远 | §4.4 |
| 一直摆不停 | C1 加大 | §10.2 |

> **顺序永远是：先怀疑接线 → 再怀疑机械 → 最后才怀疑参数。**
> 零基础最容易犯的错是"一不对就调参数"，把原本对的也调乱了。

---

## 10. 每天收工前三件事

1. **拍照**：面包板/板子正反面、机械状态
2. **记数据**：今天测到的电压、频率、角度、时间
3. **断电收好**：板子放纸盒，别压在元件上
