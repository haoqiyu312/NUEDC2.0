# 第一部分 看懂原理

## 1. 先把整件事想明白

你要做的是：**转动一个旋钮，帆板就尽量停在你指定的角度**。风扇离远了、风力变了，电路要自己发现偏差并调整。

| 你看到的东西 | 它负责什么 | 详见 |
|---|---|---|
| 面板上的电位器 P1 | 告诉系统"我想要多少角度" | 方案 5.2 |
| 帆板转轴上的电位器 P2 | 告诉系统"现在是多少角度" | 方案 5.3 |
| 减法器 | 比较想要的角度与实际角度 | 方案 5.4 |
| PI 控制器 | 根据偏差决定增加还是减少风力 | 方案 5.5 |
| 三角波与比较器 | 把控制电压变成一串通断信号 | 方案 5.6、5.7 |
| 功率管 IRLZ44N | 按通断信号控制风扇电流 | 方案 5.8 |
| 机械结构 | 让帆板能转、能读角度、整机牢固 | 方案 4 |

把过程连起来读：

```
你转 P1 → 设定电压改变 → 与 P2 的反馈电压比较
                              ↓
帆板转动 ← 风力改变 ← 风扇电流改变 ← 控制器调整输出
    ↓
P2 随轴转动 → 新反馈电压 → 再比较 → 再调整……
```

这条绕回来的路线叫**闭环**。**它不是转到目标就停止工作，而是一直比较、一直调整。**

⚠️ 本题要求纯模拟电路、洞洞板、一个整体结构、转轴处量角器、不可自动调速的风扇；正式自由落体后**不许调试、不许修复**。理解和制作都必须遵守。

## 2. 题图里的三个量

| 符号 | 白话解释 | 最容易量错的地方 |
|---|---|---|
| **θ** | 帆板离**竖直向下**方向偏了多少 | 不是与水平面的夹角，也不是把下位限位当零点 |

## 3. 机械为什么会影响控制

### 3.1 为什么帆板不能随便装在轴上

风把帆板往外推，重力把总重心往轴的正下方拉。两种作用在某个角度达到力矩平衡，帆板才有可能停在那里。

> "力矩"可以理解为**让物体绕轴转动的作用**。推门时手离门轴越远越容易推开，就是力矩的直觉。

重力力矩公式 `m·g·r·sinθ` 里：

| 符号 | 含义 |
|---|---|
| m | 所有随轴一起转动部件的总质量 |
| g | 重力加速度 |
| r | 总重心在轴下方的距离 |
| sinθ | 角度改变后，重力产生转动作用的比例 |

**总重心在轴下方，才有回到竖直的重力回复作用。** 恰好在轴上，回复作用就消失了；移到轴上方，还可能自行翻转。

⚠️ 有回复力矩并不等于闭环一定稳。摩擦、风场、风扇响应和控制器参数都还会影响结果。

### 3.2 上方配重不是让它更容易往下掉吗

**先看位置，再看质量。** 板在轴下方，配重在轴上方，两者共同决定总重心。上方配重离轴越远，会把总重心往轴的方向拉近。

| 调整动作（配重质量不变） | 总重心变化 | 一般趋势 |
|---|---|---|
| 上方配重**往上移**（远离轴） | 向轴靠近 | 回复力矩减小，同样风力吹得**更高** |
| 上方配重**往下移**（靠近轴） | 离轴更远 | 回复力矩增大，同样风力吹得**更低** |

这里的"可能"很重要：实际还要看风有没有吹到板上、转轴有没有卡住。**不凭感觉一直移动到总重心越过轴。**

### 3.3 各部件该承担什么

| 部件 | 应承担 | 不应承担 |
|---|---|---|
| 转轴和轴承 | 支撑帆板，让它顺畅转动 | 靠摩擦卡住目标角度 |
| 电位器 | 跟着转轴转，把位置变为电压 | 支撑帆板重量、承受落地冲击 |
| 柔性连接（硅胶管） | 传递转动，容许少量安装偏差 | 打滑后仍假装角度准确 |
| 限位 | 限制运动范围，保护结构和电位器 | 证明全角度范围都能连续闭环 |

⚠️ **先做纸样排布，再下料。** 板能静止放进去，不代表转起来不碰底座；还要检查配重杆和指针的运动空间。

## 4. 电路入门：只理解本题用到的

### 4.1 电压、电流、地

| 词 | 在本项目中怎样理解 |
|---|---|
| 电压 | 两点之间的电位差。说"某点电压"通常指它相对 GND 的电压 |
| 电流 | 流过支路的电荷流动；风扇支路比信号支路需要大得多的电流 |
| GND／地 | 本电路共同的电压参考点，**不一定**连接建筑物的保护接地 |
| **共地** | 各模块用同一个参考点，模块之间的电压才有共同含义 |
| 电源轨 | 电源能提供的上下边界；输出碰到边界后不能继续按理想公式变化 |

> **量电压**：黑表笔接 GND，红表笔碰测试点。
> **量电阻/通断前必须断电**；不能在带电电路上用电阻档排查短路。

### 4.2 为什么供电电压与信号电压不同

**芯片的供电像能源，输入信号像要处理的信息。** 输入是较低电压，并不要求芯片只能用同样电压供电。

本方案供电与信号分属两个电压域：
- **12V**：风扇、运放、比较器的能源
- **0~5V**：所有信号（电位器、误差、控制电压、三角波、PWM）

运放保留较高供电，是为了处理信号时有足够输出余量；**比较器供电 12V、输出上拉 5V** 也各有作用，不能为了"统一"接在一起。

⚠️ "信号按较低电压规划"不代表输出永远被限制在这个范围。故障或大误差时会饱和，要对照方案第 1.2 节各节点范围。

### 4.3 电阻、电容在这里干什么

| 元件 | 本项目里的作用 | 理解重点 |
|---|---|---|
| 电阻 | 分压、设定放大倍数、限制电流、上拉和下拉 | 相同外观不代表阻值相同，先辨认再焊 |
| 电容 | 去耦、储存电荷、产生随时间变化的信号 | 不同用途不能只按容量随便替换；电解有极性 |
| 二极管 | 在指定方向导通，提供保护电流路径 | 方向必须核对 |

**"去耦"**指在芯片附近提供短暂的电流支撑，减轻电源扰动。**它不负责修复接线错误。**

## 5. 电位器如何把角度变成电压

电位器可以想成**"一条电阻轨道 + 一个会移动的触点"**。两端接电源与地，中间滑动端就取出随位置变化的电压。

P1 由你的手转，P2 由帆板转轴带动。**两个通道必须用同一套"电压↔角度"标定，电路比较出来的偏差才代表角度偏差。**

> **注意：两个电位器不一定是同一种型号。**
> 本项目 P1 用便宜的 B10K 碳膜（约 270°），P2 用 WDD35D4 精密电位器（约 345°）。
> **两者斜率不同**——同样转 1°，P1 变 18.5mV、P2 变 14.5mV。
>
> 这不影响电路工作（两者都是线性分压），但带来一个后果：
> **P1 的旋钮刻度会变密**（帆板 10→60° 只需 P1 转约 39°），
> 而且碳膜本身的非线性会让中间角度偏一点，所以**标定要标 7 个点，不能只标 3 个**。

⚠️ 电位器**不是**给风扇直接供电的调速器。它在本方案中提供小电流信号；不能把普通信号电位器串在风扇电源里替代功率驱动。

### 5.1 为什么后面还要接跟随器

电位器的滑动端一旦被后级抽取电流，电压就可能偏离原值。跟随器读取这个电压，再用自己的输出带动后级，**尽量减轻后级对电位器的影响**。

跟随器的目标是"输出电压跟着输入电压"，**不是把电压放大**。

### 5.2 为什么一定要实际标定

电位器总转角、安装起点、连接是否打滑，都会影响真实读数。**仅凭型号不能保证做出的角度与电压正好符合规划表。**

标定就是：用量角器确定实际角度 → 记录反馈电压 → 再找到设定电位器上对应的位置。

若测到的斜率与规划表不同，要**先查清机械映射和电路是否具备所需调整能力**，不能只改旋钮标签就宣称已满足。

## 6. 减法器为什么输出不是零

电路只有单电源，处理正负误差时，把"没有偏差"放在**中点基准**（2.5V）附近更方便。

减法器比较的是反馈与设定的差，再叠加中点基准：

| 实际角度 | 反馈与设定关系（假设已正确标定） | 减法器输出 |
|---|---|---|
| 小于目标 | 反馈电压较低 | **低于**中点基准 |
| 等于目标 | 两个电压相等 | **等于**中点基准 |
| 大于目标 | 反馈电压较高 | **高于**中点基准 |

所以，**"误差为零"说的是"相对中点的偏差为零"，不是"该测试点对地电压为零"。**

公式：`V_err = 2.5V + (V_fb − V_set)`

> **注意方向是"实际 − 设定"**，不是"设定 − 实际"。接反了会变成正反馈，角度越偏风扇越往偏的方向推。

## 7. 控制器如何决定增加多少风

### 7.1 P：看现在差多少

比例作用类似于：**偏差大就做较大的调整，偏差小就做较小的调整。**

它能迅速反应，但太强时可能推过头，随后反向纠正，来回摆动。

### 7.2 I：看偏差持续了多久

积分作用把**持续存在**的偏差累积起来。即使当前只差一点，只要一直差着，控制量仍会继续变化。

| 情况 | 可以怎样理解 |
|---|---|
| 偏差短暂出现后消失 | 积分只累积了短时间 |
| 小偏差一直存在 | 积分会持续累积 |
| 输出已达极限、偏差仍存在 | 可能继续积累，出现**积分饱和**，恢复需要时间 |

**误差消失后，积分可以保留维持风力所需的控制量。** 所以"角度达到目标"并不意味着风扇必须停止，也不意味着控制输出必须回到中点。

### 7.3 复位键究竟做什么

复位键**短接积分电容**，清除其储存状态，便于开发阶段比较参数。

它**不修复接错的线、不改变机械结构**，也不保证按下后控制输出一定等于中点。

⚠️ 正式测评是否允许距离变化后手动复位，应向出题方确认；**不能把依靠人工按键的结果当作已证明的自动恢复能力**。

## 8. PWM 为什么能控制风扇

PWM 的意思是：**快速重复接通和断开，并改变每次接通所占的比例。** 这个比例叫**占空比**。

```
接通时间短： __|‾|_____|‾|_____|‾|___
接通时间长： __|‾‾‾‾|__|‾‾‾‾|__|‾‾‾‾|_
                 ← 一个周期 →
```

（这是概念示意，不是实测波形。）

三角波周期性升降，比较器把控制电压与三角波比较，决定输出每一瞬间为高还是低：

| 部分 | 作用 |
|---|---|
| 三角波 | 提供重复变化的比较基准 |
| 控制电压 | 决定每个周期内高电平持续多久 |
| 比较器 | 作出高低判断 |
| 功率管 | 按判断结果接通或切断风扇电流 |

⚠️ **占空比、转速、风力和角度是不同的量。** 占空比变化一倍，不代表转速、风力或角度也变化一倍。风扇内部电路、起转门槛和风场都需要实测；**低占空比不转是可能的**。

## 9. 功率管、上拉和下拉

| 名称 | 白话解释 |
|---|---|
| IRLZ44N | 由栅极电压控制的功率开关 |
| G 栅极 | 接收控制信号 |
| D 漏极、S 源极 | 构成风扇电流通路的一部分 |
| **上拉电阻** | 比较器不拉低输出时，给输出提供通向高电平电源的路径 |
| **下拉电阻** | 无有效驱动时，帮助栅极回到低电平，避免悬空 |
| **续流二极管** | 提供保护路径，减轻切换引起的电压冲击 |

**低端驱动**是把功率管放在风扇负端与地之间。因此**风扇负端是开关节点**，不能为了"接地整齐"直接接到地线上，否则会绕过功率管。

# 第二部分 学会它

## 10. 先看三个结论

**① 方向没选错。** 四个方向里只有控制方向是"无单片机、无代码、无 PCB、无仿真必需"的：
电源组要单片机程控 + 画 PCB，测量组要自动平衡电桥 + ADC + 校准算法，通信组要 40MHz 滤波器 + 扫频系统。
而本题 70 分的基本要求，本质就是 **4 个芯片 + 几个电阻电容 + 一块洞洞板**。

**② "先学完再做"在这个题上一定翻车。**
零基础把模电学到"能动手"要 60~100 小时。所以这份课程只有 **12.5 小时**，而且**必须在第 3 天结束时就动烙铁**，剩下靠"边做边补"。

**③ 目标锁"基本要求 70 分"。**
发挥部分的 30 分依赖风扇线性度和帆板阻尼，第一次做不一定拿得到。**70 分已经够进队。**

## 11. 必学清单 M1~M6

勾选式。每个模块都写了**"学到什么程度就算过"**——达到就停，别往下深挖。

### M1　工具与元件识别（1.5 h）

零基础**最容易卡住**、也最没人教的一环。不会用万用表，后面全部白搭。

- [ ] **万用表四个档**：直流电压（V⎓）、电阻（Ω）、通断（蜂鸣）、二极管档。会读数，会看小数点。
- [ ] **共地（GND）**：所有模块的"地"必须连在一起。**这是零基础第一号事故来源**。
- [ ] **元件读数**：
  - 电阻：色环（或贴片数字 103 = 10kΩ）
  - 电容：`104` = 0.1µF，`105` = 1µF；电解电容有极性（长脚正、条纹负）
  - 二极管 1N4007：**白/银色环那端是阴极（负极）**
- [ ] **电位器三个脚**：两端是总阻值（10kΩ），中间是滑动端。**B 型 = 线性**（A 型对数、C 型指数）。
- [ ] **IC 方向**：DIP-8 看**缺口**，缺口在左时左下角是 1 脚，逆时针数 1→8。
- [ ] **面包板 vs 洞洞板**：面包板插着试，洞洞板焊死。题目要求**最终必须焊在洞洞板上**。

**过关标准**：闭眼能说出万用表哪个档测什么；拿到电阻能读阻值；能把电位器接成 0~5V 分压并测出来。

### M2　焊接（1.5 h 学 + 3 h 练）

纯模拟题的"发挥部分（焊接、机械结构）"就靠这个拿分。**练 3 小时，别省。**

- [ ] **五个标准动作**：烙铁头同时贴焊盘和元件腿 → 停 1 秒预热 → 送焊锡 → 撤锡 → 撤烙铁
- [ ] **温度**：有铅焊锡 320~350℃；无铅 350~380℃。烙铁头要一直挂锡（防氧化）
- [ ] **三种坏焊点**：虚焊（锡球不贴焊盘）、连锡（两盘被一坨锡粘住）、冷焊（发暗、豆腐渣状）
- [ ] **洞洞板走线三招**：元件腿弯折当导线 / 单芯线走背面 / 镀锡把走线加粗
- [ ] **DIP-8 一定焊插座**，不要直接焊芯片
- [ ] 安全：烙铁架、别烫电源线、通风

**练习板（必做）**：7×9cm 洞洞板上焊 20 个电阻 + 10 根跳线 + 1 个 DIP-8 座，焊完用通断档逐个量，**要求 20/20 全通、无连锡**。

**过关标准**：3 秒内焊出光亮饱满的焊点；能自己修好一个连锡。

### M3　电路基础：只要 6 个概念（2.5 h）

**不要看《模拟电子技术》教材**（那本书第 2 章就能吃掉你三天）。只要这 6 个：

- [ ] **欧姆定律** U = I·R，功率 P = U·I
- [ ] **分压公式** `Vout = Vin × R2/(R1+R2)`。**电位器就是一个可调分压器**，这是本题角度传感的全部原理
- [ ] **串并联**：串联相加；并联 `1/R = 1/R1 + 1/R2`
- [ ] **电容 + RC 时间常数** τ = R·C。电容"隔直通交"、会充放电、会滞后。**PI 里的 I 就是它**
- [ ] **二极管单向导通 + 续流**：电机是电感，断电瞬间产生反向高压，必须在风扇两端**反着并一个 1N4007**
- [ ] **MOSFET 当开关**：栅极 G 电压够高 → 漏极 D 和源极 S 导通。**N-MOS 放在低端**

**过关标准**：能用两个电阻算出一个分压值；能说清风扇两端为什么要反并二极管。

### M4　运算放大器：七件事（4 h）★ 全场核心

方案的 80% 都在这一个模块里。**这 4 小时是整份课程里唯一不能打折的。**

- [ ] **两条黄金法则**：**虚短**（负反馈时 V+ ≈ V−）、**虚断**（输入端不流电流）
- [ ] **① 电压跟随器（缓冲）**：输出 = 输入。作用是**隔离阻抗**
- [ ] **② 反相/同相放大**：`Vout = −Vin × Rf/Rin`（反相）、`Vout = Vin × (1 + Rf/Rin)`（同相）
- [ ] **③ 差分放大器（减法器）**：四个等值电阻时 `Vout = V+ − V−`，本题实际是 **`V_err = 2.5V + (V_fb − V_set)`**
      **注意方向是"实际 − 设定"**
- [ ] **④ 偏置/中点**：单电源没有负电压，所以信号要"抬"到 2.5V 附近摆动。用两个 10k 分压，**再经一级跟随器缓冲**
- [ ] **⑤ 积分器**：`Vout = −(1/RC)·∫Vin dt`。误差持续存在 → 输出持续累积 → 直到误差归零才停
- [ ] **⑥ 比较器**：运放开环用，V+ > V− 输出高。**PWM 就是这么来的**
- [ ] **⑦ 饱和（顶到轨）**：运放输出最大只能到电源附近。**这是本题最大的隐蔽杀手**

**过关标准**：给你一张运放电路图，能说出"这是跟随器/减法器/积分器"，并能用虚短虚断算出输出表达式。

**必须自己动手的 4 个面包板小电路**（每个 20 分钟，比看 4 小时视频管用）：
1. 分压器 → 跟随器 → 万用表测，转电位器看输出跟着变
2. 减法器 → 两个电位器分别给 2.5V 附近的两个电压 → 应该看到 `2.5 + (V_fb − V_set)`，而且 **V_fb 调大、输出跟着变大**（方向反了就是接反了）
3. 积分器 → 输入接 2.5V 直流 → 看输出慢慢爬到饱和（**亲眼看到"饱和"**）
4. 比较器 → 一个电位器当参考，一个当输入 → 看输出跳变

### M5　闭环与调参：只学"手感"（1.5 h）

**不要学拉普拉斯变换、传递函数、伯德图。** 一周之内学这些，一个字都用不上。

- [ ] **六个词**：设定值／实际值／误差／执行器／被控对象／传感器
- [ ] **负反馈**：误差越小，输出越小。误差为零，系统就稳住了
- [ ] **P（比例）**：误差大 → 风扇转得快。**P 太大会来回振荡**
- [ ] **I（积分）**：慢慢累积误差，把"总是差那么几度"补掉。**I 太强也会振荡**
- [ ] **为什么这题必须有 I**：风扇转速和角度不是线性关系（风压 ∝ 转速²），纯 P 一定差几度，题目要求 ±5°，靠 I 补
- [ ] **调参口诀（这题专用）**：**先要阻尼，再慢调 I**
      ① 拨一下帆板看它晃几下停（晃超过 4 个来回 = 必须先加阻尼）
      ② 只用积分，调 C1（太大→慢，太小→来回摆）
      ③ 比例 R8 保持很小（22k 起，最多 47k）
      > ⚠️ 网上通用的"先 P 后 I、先找临界振荡"在这题上是**错的**——会把帆板 2.3Hz 的谐振激起来。
- [ ] **物理直觉**：帆板 = 重力想把它拉回竖直 + 风力想把它推倒，角度是两个力矩的平衡点。
      所以 **角度越大，需要风越大** —— 天然单调，控制很好做。**前提是总重心必须在转轴下方。**

**过关标准**：能说出"角度一直差 3° 调不上去该动哪个参数"（答案：先确认不是转轴干摩擦，再加大 C1 让积分更充分）。

### M6　仪器与测量（1.5 h）

- [ ] **万用表**：测电压**并联**、测电流**串联**（串错会烧保险丝）
- [ ] **示波器**：探头 1×/10× 别搞混；**地夹必须夹在电路的地上**；会调时基（TIME/DIV）和垂直档（VOLTS/DIV）；不会触发就按 AUTO
- [ ] **示波器看三个波形**：三角波（频率、峰峰值）、PWM（占空比随 V_ctrl 变）、运放输出（**看它是不是顶在 0V 或 12V 不动了 = 饱和**）
- [ ] **量角度**：量角器 + 指针；手机装"角度测量"APP 交叉验证
- [ ] **记录数据**：拿个本子，每调一次参数记一行（参数／角度／恢复时间）。**没有记录就没有调参，只有瞎试**

**过关标准**：能把示波器调出一个稳定不飘的 2kHz 方波，并读出占空比。

## 13. 六个必须避开的坑

这些是仿真和 Multisim 验证中真实踩到的。**动手前先看完，能省好几天。**

### 坑 ①　IRF540 用 5V 栅极驱动，吃不饱

- **问题**：IRF540N 不是逻辑电平管。它的 `Rds(on)` 标在 **Vgs = 10V**；5V 驱动时处于"半开"状态，离散性大。
- **怎么改**：换 **IRLZ44N**（逻辑电平，Vgs=5V 就能完全导通）。

### 坑 ②　LM358 在 5V 下输出到不了 4.5V

- **问题**：LM358 单电源 5V 时，输出最高只到 Vcc − 1.5V ≈ **3.5V**。而 V_ctrl 要到 4.23V。
  结果是**风扇最大只到 ~75% 转速，帆板到不了 60°**，而且波形看着"挺正常"，根本查不出原因。
- **怎么改**：**运放供电从 5V 抬到 12V，信号仍然是 0~5V。**
  LM358 在 12V 下输出能到 10.4V，**连运放型号都不用换**。
- **连带改动**：中点是 **2.5V**（从 5V 分压），三角波落在 **0.95~4.23V**。
- **顺带**：`7809 → 7805` 两级串联可以省掉，直接 12V + 一个 7805。

### 坑 ③　"帆板重心落在转轴上"是错的

- **问题**：总重心正好在轴心上 → 重力力矩 = 0 → **没有回复力矩**。
  风扇只要有一点风，帆板就一直转到撞限位；要停在 45°，风扇必须精确输出"零力矩"，而单向风扇做不到。
  **系统没有稳定平衡点，控制无从谈起。**
- **怎么改**：让**总重心明显低于转轴**（轴上方加配重）。
  于是 `重力回复力矩 = m·g·r·sinθ`，风越大 θ 越大，**天然单调、自带稳定平衡点**，PI 调起来容易十倍。
- **判据**：100% 占空比时帆板打到 **68~72°**。

### 坑 ④　PI 的结构和参数都不对

- **问题 1（结构）**：把电阻和电容**并联**在反馈回路上，直流增益只有 Rf/Ri = 10，稳态误差压不到零，角度会稳定地差几度。
- **问题 2（参数）**：`R7=10k, R8=220k, C1=1µF` → **Kp=22、积分时间常数 R7·C1=10ms**，积分比对象快 100 倍 → 一上电就是"满速—停—满速"来回撞限位。
- **怎么改**：结构用**串联 RC 真积分**；数值用 **R7=100k、R8=22k、C1=6.8µF 薄膜**（Kp=0.22，积分时间常数 R7·C1=0.68s）。
- **C1 必须薄膜**，不能电解（漏电流会让积分失效）。

### 坑 ④b　帆板是"会自己晃"的谐振体

- 帆板不是乖乖跟着走的慢对象，它是 **约 2.3Hz 的轻阻尼弹簧振子**。
- 仿真结论：**ζ=0.04 会持续振荡；ζ=0.05 勉强 15 秒收敛；ζ ≥ 0.08 才拿得到 5 秒。**
- 零成本做法：转轴点一滴硅油 / 加一小片挡风板。
- 判断：**拨到 45° 松手，晃 1~2 下就停 = 够了；晃 4 下以上 = 不够。**
- **好消息**：基本要求没有时间指标，所以阻尼差只丢发挥分，不丢基本分。

### 坑 ④c　帆板材料选错，风扇再大也吹不到 60°

- 帆板尺寸题目定死 **10×15cm**，材料和厚度自定 → **质量是唯一能调的机械参数**。

| 质量 | 材料 | d=15cm 能到 | d=25cm 能到 | 判定 |
|------|------|------------|------------|------|
| 5 g | 2mm 硬纸板 | 75.8° | 71.7° | ✅ |
| 10 g | 1.5mm 硬纸板+加强 | 70.0° | 64.4° | ✅ 上限 |
| 15 g | 1mm 亚克力 | 65.6° | 58.9° | ⚠️ 只够基本要求 |
| 30 g | 2mm 亚克力 | 56.2° | 47.4° | ❌ 吹不到 60° |

- **结论：用硬纸板或泡沫板，别用亚克力。** 板子看着薄，其实太重。
- 附带一个反直觉的结论：**谐振频率和质量无关**（刚度与惯量都正比于质量），换材料只影响"吹不吹得动"，不影响"好不好控"。

### 坑 ⑤　风扇有"启动死区"

- **问题**：直流风扇在低占空比下（典型 30~40%）**根本不转**。所以 10°~15° 这段靠电路控不住。
- **怎么改**：
  - 买**大直径低转速**风扇（120mm 比 92mm 好），把工作点推到线性区
  - **帆板做轻**（≤10g），转动惯量小、响应快
  - **转轴处加下位限位**（10°），作为双保险
- **好消息**：仿真显示 u0 在 0.20~0.55 之间，三个角度都做得到——积分器会自己把工作点顶上去。

### 坑 ⑥　积分器开机就饱和

- **问题**：刚上电时 C1 上是 0V、误差很大，积分器会一路冲到电源轨，之后要好几秒才"退回来"。
  表现是**开机后风扇全速狂转十几秒**。
- **怎么改**：加**复位键**（在 C1 两端并一个轻触开关），按下时把积分电容短路清空。
  上电、换 d、换配重之后按一下。
- 另外养成习惯：**上电前先把设定电位器拧到实际角度附近**。

### 另外三个小提醒

- **共地**：12V 地、5V 地、所有运放地、MOS 源极地必须全部连通。焊板子时先用一根粗线把"地"铺出来。
- **减法器的 4 个电阻必须等值、1% 精度**，随便抓 4 个 10k 会有 5% 的共模误差。
- **电位器的轴不能承重、不能受冲击**：让机械轴自己承重（用轴承），电位器用**柔性连接**（硅胶管）跟着转。

## 16. 读完后用自己的话回答

| 问题 | 回答应包含的关键意思 |
|---|---|
| 为什么要两个电位器？ | 一个给目标，一个反馈实际角度 |
| 为什么实际角度变了电路能发现？ | 转轴带动反馈电位器，使反馈电压变化 |
| 为什么总重心不能在轴上？ | 需要重力回复作用；在轴上会使它消失 |
| 为什么目标达到后风扇还要转？ | 仍要用风力平衡重力力矩 |
| 为什么不能一上来调控制器？ | 接线、机械摩擦或反馈方向错误，都可能被误认为参数问题 |
| 为什么不能只用万用表确认 PWM 正常？ | 平均电压不能完整显示频率、极性、峰值和占空比 |
| 减法器的输出为什么不是 0V？ | 单电源中点偏置；"误差为零"是相对 2.5V |
| 误差的方向是哪个减哪个？ | **实际 − 设定**（V_fb − V_set）；反了就是正反馈 |
| 如果题图、方案和实测不一致怎么办？ | 先记录差异并核对依据，不凭记忆改值，不把推断写成事实 |

**读到哪一节卡住，就回到对应实物或方案小节对照。**
最先需要真正看懂的是：**目标从哪里来、实际值从哪里来、角度不够时最终驱动力应怎样变化。**
